# Demo Video Script (max 5 minutes)

## 0:00-0:25 — Hook
"Not another app to check. This agent runs in the background, researches
real trends, creates a real post in the brand's voice, publishes or stages
it honestly, and reports back like an employee — not a dashboard you have
to operate."

## 0:25-0:50 — Architecture, fast
Show the README architecture diagram. "Built on the Strands Agents SDK —
one agent, three real tools: research, generate, publish-or-stage."

## 0:50-2:30 — The real run
Screen: terminal running `python main.py`. Let the real output play:
- The trend research finding real, specific things (not generic advice) --
  point at the actual Guyanese idioms it surfaced.
- The content decision and the generated image -- cut to the actual PNG
  full-screen for a beat.
- The staging decision -- explain plainly: "Facebook posting is really
  live in this build; Instagram needs image hosting this build doesn't
  have yet, so it's staged honestly instead of faked."
- The founder report at the end -- read the "note for next cycle" line
  out loud; it's the agent proposing its own next step, not a canned reply.

## 2:30-3:00 — Why an agent, not an app
"The founder's only job is to read that one summary. Everything else --
researching, deciding, writing, generating, publishing -- happened without
anyone opening a dashboard."

## 3:00-3:20 — Honest close
"This is one full working cycle today. Instagram publishing, scheduled
recurring runs, and Bedrock/AgentCore deployment are the next steps,
documented plainly in the README as what's next, not claimed as done."

## Reminders
- Public YouTube/Vimeo upload, English audio.
- Max 5 minutes -- this one has more room to breathe than a 3-minute limit.
- Show it running for real, not narrated over static slides.
